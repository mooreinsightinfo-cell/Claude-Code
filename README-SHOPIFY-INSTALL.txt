MOORE INSIGHT SHOPIFY THEME — EDITABLE INTERFACE
=================================================

Upload instructions:
1. Go to Shopify Admin > Online Store > Themes.
2. Click Add theme > Upload zip file.
3. Upload this ZIP file.
4. Click Customize — every section is now editable in the Theme Editor sidebar.

What you can edit in the Theme Editor:
---------------------------------------
NAVIGATION
  - Brand name & tagline
  - "Enter the Shop" nav button text

HERO SECTION
  - Eyebrow text
  - Main heading (italicise any word to make it render in gold)
  - Subtext paragraph
  - Primary & secondary button text and links

PILLARS SECTION
  - Kicker, heading, description
  - Each pillar: symbol, title, description
  - Add, remove, or reorder pillar blocks via the "Pillars" block list

CONSULTING SECTION
  - Upload a custom image (falls back to queen.png asset)
  - Kicker, heading, description
  - Up to 4 service list items (leave blank to hide any item)
  - Button text and link

SHOP / PRODUCTS SECTION
  - Kicker, heading, description
  - Each product card: symbol, category tag, title, description, price, link
  - Add, remove, or reorder product cards via the "Product Card" block list

QUOTE SECTION
  - Quote text and attribution

ABOUT SECTION
  - Upload a custom image (falls back to king.png asset)
  - Kicker, heading, body paragraphs
  - Button text and link

CTA SECTION
  - Heading (italicise a word to make it gold)
  - Subtext, button text and links

CONTACT
  - Email address (used in mailto links throughout)

FOOTER
  - Brand description text
  - Social links: YouTube, TikTok, Instagram (leave blank to hide)
  - Privacy Policy & Terms of Service links
  - Copyright line and tagline

Notes:
- Optional image assets referenced by the design: banner.png, queen.png, king.png.
  Upload files with those exact names via the Shopify theme code editor (Assets),
  or use the image picker in the Theme Editor for consulting and about sections.
- Product cards are styled landing-page cards. To connect real Shopify products,
  replace the product_card blocks with Shopify's built-in product blocks later.
- Italicising a word in any richtext heading will render it in the gold gradient.
